# Priya Das — 3D Spatial Developer Portfolio

An interactive, premium 3D spatial developer portfolio showcasing AI capabilities and systems engineering skills.

## 🚀 Key Features

* **3D Room Scene**: Fully responsive interactive 3D environment built with React Three Fiber, OrbitControls, and custom neon shader lighting.
* **Interactive Mascot**: Custom animated penguin companion that enters, departs, and plays music dynamically.
* **Proximity Constellation**: An interactive technical skills grid built with GSAP mapping that scales elements based on cursor proximity.
* **Optimized Loading**: Integrated progress tracking overlay for 3D assets and lazy-loaded project card skeletons to minimize layout shifts.

## 🛠️ Tech Stack

* **Frontend**: React (Vite), Tailwind CSS
* **3D Rendering**: Three.js, `@react-three/fiber`, `@react-three/drei`
* **Animations**: GSAP (GreenSock), Framer Motion
* **Smooth Scrolling**: Lenis Scroll Engine

## 💻 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run dev server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
